# Gaze Lab — веб-айтрекинг по камере (прототип)

## Что в репозитории
| Файл | Назначение |
|---|---|
| `index.html` | Live-трекинг взгляда с веб-камеры (webgazer): калибровка 9 точек, запись сессии, heatmap, scanpath, экспорт JSON |
| `attention-predict.html` | Предиктивная тепловая карта внимания для статичного изображения (CSS-аналог saliency) + AI-разбор карточки через Claude |

## Как запустить локально
Камера доступна только в **secure context** (HTTPS или localhost):

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/index.html
```

Для публикации — любой хостинг с HTTPS (GitHub Pages, Netlify, Vercel).

## Важные ограничения webgazer (честно о продукте)
- Точность веб-айтрекинга без ИК-датчиков — **десятки пикселей**, это демо/прототип, а не измерительный инструмент.
- Модель обучается на лице пользователя во время калибровки; при плохом освещении качество резко падает.
- Поддержка: desktop Chrome/Firefox/Safari; мобильные браузеры — нестабильно.
- Веб-камера обрабатывается **полностью на клиенте**; видео никуда не отправляется. Экспортированные сессии содержат координаты взгляда — при работе с реальными пользователями это персональные данные (GDPR/152-ФЗ: согласие, хранение, анонимизация).

4. **Замена движка**: оценка OpenGazer / EyeCloud API / Tobi Pro SDK для продакшн-точности.
5. **Инфраструктура**: CI (eslint + playwright smoke-тест), тестовая страница с размеченными AOI, сбор метрик точности после калибровки.
